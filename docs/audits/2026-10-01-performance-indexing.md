# Проверка скорости и доступности для поиска

Дата: 1 октября 2026. Сайт: https://my-wish-list.online/ после PR #27.

## Мобильная загрузка

Chromium через Playwright, 390 x 844 px, DPR 2, холодный браузерный кеш,
сеть 1,6 Мбит/с с задержкой 150 мс, замедление CPU в 4 раза.
По два прогона, наблюдение до пяти секунд после load. Эти лабораторные
результаты не являются Lighthouse-оценкой или полевыми Core Web Vitals.

| Страница | LCP, секунды | CLS | TTFB, мс |
| --- | --- | --- | --- |
| Главная | 2,25–2,58 | 0 | 524–584 |
| /gifts | 1,87–2,05 | 0 | 525–532 |
| /gifts/for-mom | 2,70–3,34 | 0 | 565–567 |
| /articles/kak-sostavit-vishlist | 1,90–1,94 | 0 | 519–531 |

Для дополнительной диагностики в отдельном браузерном контексте заблокирован
только домен mc.yandex.ru. На /gifts LCP составил 1,75–1,80 с, на
/gifts/for-mom — 2,06–2,08 с. Сумма частей длинных задач свыше 50 мс
на странице для мамы снизилась с 1721–1874 до 659–846 мс. Это диагностический
счётчик, не TBT Lighthouse и не INP. Скрипт Метрики передаёт около 95 КБ.

Изменение: загрузка Метрики перенесена с afterInteractive на lazyOnload.
Счётчик и настройки сохранены. Штатная стратегия Next.js загружает скрипт
после load в период простоя браузера. Аналитика начинает работу позже,
поэтому очень короткие визиты могут не попасть в счётчик. Замер с блокировкой
показывает потенциал улучшения, но не доказывает величину эффекта от отсрочки;
после деплоя нужен повторный замер. INP и 75-й процентиль реальных посещений
не измерялись.

## Доступность для индексации

Проверены все 38 адресов текущего sitemap: HTTP 200, один H1,
description и соответствующий canonical; noindex отсутствует в HTML
и заголовке X-Robots-Tag. robots.txt разрешает публичные страницы и
указывает правильный sitemap; закрывает /api/, /go/, /lists, /login,
/me и /tg. На главной присутствуют метатеги подтверждения Google и Яндекса.
Это не подтверждает, что сайты уже верифицированы в кабинетах.

Поисковые запросы site:my-wish-list.online и
site:my-wish-list.online/gifts/for-mom не дали результатов в доступном
поисковом инструменте. Из этого нельзя заключить, что страницы отсутствуют
в Google или Яндексе. Официальный статус индексации недоступен без
Search Console и Яндекс Вебмастера. PageSpeed API вернул HTTP 429
(суточная квота API), поэтому оценка PageSpeed и данные CrUX не получены.

## Следующие действия

1. После деплоя повторить мобильный замер и проверить загрузку счётчика.
2. В Search Console проверить sitemap и URL Inspection для главной,
   /gifts, /gifts/for-mom и одной статьи: индексирование, выбранный Google
   canonical, дату последнего обхода и причину исключения, если она есть.
3. В Яндекс Вебмастере проверить Sitemap, страницы в поиске и диагностику.
4. По данным кабинетов выбирать следующие изменения содержания и внутренних
   ссылок; не добавлять новые страницы только ради их количества.

## Проверка изменения

Production-сборка и 466 тестов прошли. В шести браузерных проверках
главной, /gifts и /gifts/for-mom при ширине 390 и 1440 px запрос
скрипта Метрики выполнялся после load, инициализация происходила один раз,
настройки webvisor и trackLinks сохранялись. Внешний скрипт в этой проверке
заменён тестовой заглушкой: доставка событий в кабинет Метрики не проверялась.
