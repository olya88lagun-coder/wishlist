# Детское оформление и приглашения

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans. Steps use checkbox syntax for tracking.

**Goal:** Разовая покупка детского оформления одного вишлиста за 149 ₽ либо оформления с приглашением PNG за 199 ₽.

**Architecture:** Бесплатный «Журнал» сохраняется. Сервер хранит заказы, проверяет платежи через API ЮKassa и выдаёт права только после подтверждения суммы, валюты, режима и привязки заказа. Редактор приглашения доступен владельцу; экспорт PNG проверяет права повторно. Данные приглашения передаются POST-запросом, не сохраняются и не появляются на публичной странице.

**Tech Stack:** Next.js, React, Drizzle/PostgreSQL, ЮKassa Redirect API, next/og, QRCode, Lucide.

- [x] Права и заказы: тесты цен, владения, повторной обработки и неподтверждённых оплат; миграция и серверные функции.
- [x] Оплата: идемпотентное создание, серверная проверка webhook и возврата, выключенный по умолчанию запуск продаж, инструкция настройки без секретов в Git.
- [x] Тема: оригинальная декоративная иллюстрация, предпросмотр и применение купленной темы; неизменные фотографии подарков и бронирование. По уточнению пользователя добавлены голубая и розовая расцветки.
- [x] Приглашение: имя, возраст, дата, время, место, сообщение; PNG 1080×1440 с QR-кодом; текст со ссылкой для MAX, Telegram и ВК. Адрес не публикуется и не хранится.
- [x] Проверки: 827 unit/integration-тестов, typecheck, build; 2 Playwright-теста mobile/desktop, экспорт и декодирование QR. Дополнительная проверка 320/390/1440 px. Без реальных списаний, мержа и деплоя.

**Решения:** Приглашение — картинка, не отдельная публичная страница. При докупке приглашения после темы доплата 50 ₽. Продажи требуют явного включения, настроек магазина и чеков, ссылки на согласованные условия продавца. Настоящие ключи устанавливаются только на сервере. ЮKassa у владельца есть, к сайту пока не подключена.
