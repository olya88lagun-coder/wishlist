**Interfaces:**

- Produces: решение «открываем / дорабатываем / меняем идею» с обоснованием.

Критерии заданы заранее, чтобы решение не подстраивалось под желаемое.

- [ ] **Step 1: Документ с критериями**

`docs/beta/exit-review.md`:
```markdown
# Итог беты

Период: … — …  Участников пришло: … из … приглашённых

## Критерии публичного запуска

| # | Критерий | Порог | Факт | Выполнен |
|---|---|---|---|---|
| 1 | Открытые P1 | 0 | | |
| 2 | Доля участников, создавших список | ≥ 70% | | |
| 3 | Доля списков с 3+ подарками | ≥ 50% | | |
| 4 | Доля списков с бронями (ссылкой поделились, гости пришли) | ≥ 30% | | |
| 5 | Пришли сами: пользователей больше, чем согласившихся участников (гости создали свои списки) | ≥ 3 человек сверх | | |
| 6 | «Порекомендовали бы» в ответах дня 14 | ≥ 60% ответивших | | |
| 7 | Сбои прода за бету (canary, проверка сайта, потерянные данные) | без потери данных; сбои устранены | | |

## Решение

- **Все критерии выполнены** → публичный запуск: отдельный план (продвижение к Новому году, SEO лендинга, подготовка к нагрузке).
- **Не выполнены 2–4 при выполненном 1** → ещё 2 недели беты с доработками по отзывам, затем повторная оценка.
- **Не выполнены 2 и 3** (люди не собирают списки) → разговор о самой идее: что мешает, нужен ли другой сценарий входа.

Итог: …
Почему: …

## Что узнали про деньги

- Переходы в магазин за бету: … (по магазинам: …) — достаточно ли для партнёрки (ориентир — тысячи в месяц)?
- «Хотят оформление»: … из … владельцев — есть ли спрос на платные темы?
```
