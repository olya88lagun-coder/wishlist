# Task 5: Ручная проверка перед приглашениями

**Files:**
- Create: `docs/beta/qa-checklist.md`

**Interfaces:**
- Consumes: прод после Task 4.
- Produces: заполненный чек-лист с найденными проблемами; каждая проблема — строка в таблице «Найдено» с приоритетом.

E2E-тест проверяет один путь в одном браузере. Участники беты придут с iPhone, Android, десктопа, из Telegram Mini App и из браузера — такие расхождения ловятся только руками. Проверку делает пользователь (у него устройства), ассистент ведёт чек-лист и заносит результаты.

- [x] **Step 1: Создать чек-лист**

`docs/beta/qa-checklist.md`:
```markdown
# Проверка перед бетой

Дата: …  Кто проверял: …

Отметка: ✅ работает · ⚠️ работает с оговоркой (описать) · ❌ не работает (описать)

| # | Сценарий | iPhone, Telegram | Android, Telegram | Телефон, браузер | Компьютер, браузер |
|---|---|---|---|---|---|
| 1 | Первый вход: бот `/start` → «Открыть вишлист» → Mini App открылся, вход без вопросов | | | — | — |
| 2 | Вход на сайте через Telegram и через VK ID | — | — | | |
| 3 | Создать список с датой праздника; стикер «ДР через N дней» | | | | |
| 4 | Добавить подарок ссылкой WB, Ozon, Золотое Яблоко, Яндекс Маркет; фото/название/цена или подсказка | | | | |
| 5 | Добавить подарок ссылкой из бота; карточка обновилась; «В список ▾», «Изменить», «Удалить» | | | — | — |
| 6 | Поделиться: Telegram, VK, MAX, «Скопировать»; превью со стикером | | | | |
| 7 | Гость без входа: открыть ссылку, «Открыть в магазине», забронировать, снять бронь | — | — | | |
| 8 | Гость из Telegram: бронь → подтверждение в боте → «Снять бронь» в боте | | | — | — |
| 9 | «Напомнить в Telegram» у гостя с сайта | — | — | | |

| 13 | `/feedback` доходит администратору | | | — | — |

## Найдено

| # | Где | Что не так | Приоритет | Статус |
|---|---|---|---|---|

Приоритеты: **P1** — ломает главный путь (не войти, не добавить, не поделиться, не забронировать) → исправить до приглашений; **P2** — мешает, но есть обход → исправить в первую неделю беты; **P3** — косметика → в бэклог.
```

- [x] **Step 2: Пройти чек-лист с пользователем**

По одной строке за раз: пользователь проверяет на своих устройствах и пишет результат, ассистент заполняет таблицу. Для каждой ❌/⚠️ — строка в «Найдено» с приоритетом.

- [x] **Step 3: Исправить P1**

Каждую P1 — отдельной веткой `fix/<кратко>`: воспроизвести, тест, исправление, мерж с согласия, деплой с «да», повторная проверка строки чек-листа. Приглашения (Task 6) не отправляются, пока в «Найдено» есть открытые P1.
