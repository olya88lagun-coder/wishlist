# План 7 — Закрытая бета на 20–30 человек

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. Задачи лежат в отдельных файлах `task-NN-*.md` этой папки; выполнять по порядку.

**Goal:** Пройти этап 8 спецификации: дать сервис 20–30 живым людям до новогоднего сезона, собрать ошибки и отзывы, исправить главное и по понятным критериям решить, открывать ли сервис публично.

**Architecture:** Код меняется мало: отзыв в один шаг из бота и с сайта (сообщение пересылается администратору), две доли в `/stats`, которые спека называет ключевыми (списки с 3+ подарками и списки с бронями), и один сквозной E2E-тест главного сценария на Playwright, который запускается локально и в CI. Остальное — операционные документы: чек-лист проверки перед бетой, сценарий набора и сопровождения участников, еженедельный разбор и критерии выхода.

**Tech Stack:** как в планах 1–6 + `@playwright/test` (только devDependency, браузер Chromium, на сервере не запускается).

**Spec:** `docs/superpowers/specs/2026-09-13-wishlist-mvp-design.md` (раздел 8 «Порядок разработки», п. 8; раздел 9 «E2E» и «Продуктовые метрики»)
**Предыдущий план:** `docs/superpowers/plans/2026-09-16-plan-6-growth/` (выполнен)

## Global Constraints

- Значения проекта: `APP_URL` = `https://my-wish-list.online`; бот `@my_wish_list1_bot`; сервер `root@200.169.178.231`; ветка `feat/beta`, мерж в `master` только после зелёного CI и согласия пользователя.
- Команды pnpm на машине разработчика (Git Bash): `export PATH="/c/Users/olya8/AppData/Roaming/npm:$PATH"` перед `pnpm ...`.
- **Каждая команда на сервере — только после явного «да» пользователя.**
- **Сообщения участникам беты отправляет сам пользователь** (или бот по действию участника). Никаких рассылок от имени пользователя без его подтверждения каждого текста.
- **Приватность отзывов:** отзыв пересылается администратору как сообщение Telegram (виден отправитель — он сам написал боту); в базе отзывы не хранятся. Контакты участников беты хранятся только у пользователя, не в репозитории.
- E2E-тест ходит только в локальное приложение с локальной базой (`pnpm dev:db`), не в прод.
- Тексты на русском, коротко; стиль как в приложении.
- Коммиты — conventional commits, без Co-Authored-By.

## Сроки

- Задачи 1–5 — до приглашения первых участников (ориентир — неделя).
- Бета — 3–4 недели, чтобы застать у участников хотя бы один праздник или подготовку к Новому году.
- Решение о публичном запуске — не позже середины ноября: пик вишлистов в декабре.
