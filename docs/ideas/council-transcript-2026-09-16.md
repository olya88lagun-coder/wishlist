# Совет: монетизация вишлиста (2026-09-16)

## Исходный вопрос
Как монетизировать вишлист (лендинг + ТГ-бот) в России? Платные фоны (есть сомнения в спросе) и партнёрка с Admitad: реально ли это, есть ли российские аналоги, как это работает на странице вишлиста.

## Вопрос в постановке для совета
Разработчик в одиночку делает вишлист-сервис для России: публичные страницы (my-wish-list.online) + Telegram-бот/Mini App. Подарки подтягиваются по ссылкам с WB, Ozon, Lamoda, Золотого Яблока и Я.Маркета; гости бронируют подарки без регистрации; есть кнопки «поделиться» и напоминания о днях рождения. Сервис ещё не запущен, пользователей нет.
План 6: (1) платные темы по 99/499 ₽ через ЮKassa, только на сайте; (2) партнёрские ссылки через редирект /go/:itemId с шаблоном из env (Admitad), пометкой «партнёрская ссылка» и erid.

## Ответы советников

### Критик (Contrarian) — ответ C
Обе части — одна ошибка: монетизация до трафика. Paywall тем никто не увидит, а создателю списка почти всё равно, как выглядит страница. Сети требуют трафик, так что новичку могут отказать. Даритель заходит раз в год, клик разовый. Куки короткие и перебиваются прямым заходом в приложение. ОРД — это процесс с отчётностью. «Что можно проверить за неделю, а не построить за неделю?»

### От первых принципов — ответ E
Вопрос поставлен неверно: монетизация нуля — ноль. Темы монетизируют владельца, у которого нет мотивации платить. Партнёрка монетизирует дарителя, у которого нет причины идти по вашей ссылке, а не в приложение. Стройте механизм, при котором один список рождает следующий, а напоминания — ваш вирусный крючок.

### Расширитель (Expansionist) — ответ D
Темы забыть. Партнёрки и есть основной продукт, потому что вишлист — точка покупательского намерения. Утверждал, что Admitad реален и без трафика. Предлагал подключить собственные программы WB/Ozon/Я.Маркета и выбирать сеть с лучшей выплатой. Настоящий потенциал — петля «гость → свой вишлист».

### Посторонний (Outsider) — ответ B
Платить за «обои в комнате, где живут гости», странно, а двух тем мало даже для тщеславия. По кнопке кликает даритель, который уже решил купить: клик без выбора, комиссия копеечная.

### Практик (Executor) — ответ A
Темы — в бэклог (ЮKassa, 54-ФЗ, UI). Admitad без трафика может отказать, поэтому начинать с прямых программ маркетплейсов. Механика /go правильная, атрибуцию ведёт площадка. erid обязателен. «В понедельник»: зарегистрироваться в партнёрках Ozon/WB и подключить erid.

## Перекрёстная проверка (кто скрывался под буквой: A=Практик, B=Посторонний, C=Критик, D=Расширитель, E=Первые принципы)
- Проверка 1: сильнейший — C, самое слепое пятно — D. Все пропустили: переход в приложение и поиск товара по названию убивают атрибуцию; нужен статус самозанятого или ИП; сезонность (НГ, 8 марта) как окно для fake-door; чужая реф-метка в распарсенном URL; B2B и подписка.
- Проверка 2: C / D. Никто не посчитал юнит-экономику (чек 2–5 тыс., ставка 1–3%), не учёл трафик через приложения и налоговый статус.
- Проверка 3: D / D. Никто не дал формулу «клики → рубли».
- Проверка 4 (юрист): C / D. Пропущены налоговый статус (НПД, лимит 2,4 млн), ежемесячная отчётность в ОРД, 152-ФЗ для данных гостей, оферта для ЮKassa.
- Проверка 5 (UX): C / D. Никто не продумал UI кнопки «купить», поведение /go в WebView Telegram Mini App и защиту от двойного учёта.
