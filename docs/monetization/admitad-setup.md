# Партнёрские шаблоны Admitad

Сайт строит партнёрскую ссылку из шаблона в `.env` на сервере. В шаблоне `{url}` заменяется на закодированный адрес товара или страницы. Шаблон лежит только на сервере, в репозиторий его класть нельзя.

## Формат deeplink Admitad
Проверено в кабинете 14.10.2026 для программы МТС (shop.mts.ru). Генератор deeplink программы выдаёт ссылку вида:

```
https://<домен-сети>/g/<код-площадки>/?erid=<erid>&ulp=<закодированный адрес страницы>
```

`erid` в ссылке один для площадки и программы и уже встроен в ссылку при её создании. Для каждой программы свои домен, код и `erid`: их копируют из блока «Deeplink» программы.

## Шаблон для сервера
```
AFFILIATE_MTS_TEMPLATE=https://<домен-сети>/g/<код-площадки>/?erid=<erid>&ulp={url}
```

Остальные магазины: `AFFILIATE_OZON_TEMPLATE`, `AFFILIATE_WILDBERRIES_TEMPLATE`, `AFFILIATE_LAMODA_TEMPLATE`, `AFFILIATE_GOLDAPPLE_TEMPLATE`, `AFFILIATE_YANDEX_MARKET_TEMPLATE`, `AFFILIATE_OTHER_TEMPLATE`.

## Перед включением
1. Получить от поддержки Admitad ответ про маркировку (erid, пометка «Реклама») и допустимость редиректа через `/go/`.
2. Прочитать правила программы и убедиться, что поисковые фразы и товары не нарушают их. Для Lamoda, Золотого яблока и ЛЭТУАЛЬ запреты реализованы в `packages/db/src/partner-rules.ts`.
3. Добавить строку в `/opt/wishlist/.env`, перезапустить сервис и один раз проверить переход по ссылке из списка. Не кликать по своим ссылкам повторно: программы запрещают самоклики.

## Правила МТС, важные для сайта (14.10.2026)
- Контентные сайты: можно. Контекстная реклама запрещена, слова «МТС» и «MTS» нельзя использовать в ключах для рекламы.
- Нельзя использовать креативы, не согласованные с рекламодателем, и промокоды не из сети Admitad.
- Не оплачиваются: заказы юрлиц, предзаказы, заказы, выкупленные в течение 15 минут, 4 и более заказа смартфонов в месяц от одного покупателя.
