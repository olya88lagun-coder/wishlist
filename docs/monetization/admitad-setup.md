# Партнёрские шаблоны Admitad

Сайт строит партнёрскую ссылку из шаблона в `.env` на сервере. В шаблоне `{url}` заменяется на закодированный адрес товара или страницы. Шаблон лежит только на сервере, в репозиторий его класть нельзя.

## Формат deeplink Admitad
Проверено в кабинете 14.10.2026 для программы МТС (shop.mts.ru). Генератор deeplink программы выдаёт ссылку вида:

```
https://<домен-сети>/g/<код-площадки>/?erid=<erid>&ulp=<закодированный адрес страницы>
```

`erid` в ссылке один для площадки и программы и уже встроен в ссылку при её создании. Для каждой программы свои домен, код и `erid`: их копируют из блока «Deeplink» программы.

## Шаблон для сервера
```
AFFILIATE_MTS_TEMPLATE=https://<домен-сети>/g/<код-площадки>/?erid=<erid>&ulp={url}
```

Проверено в кабинете 14.10.2026:
- **МТС Shop** (`AFFILIATE_MTS_TEMPLATE`): `https://<домен>/g/<код>/?erid=<erid>&ulp={url}`.
- **Читай-город** (`AFFILIATE_CHITAIGOROD_TEMPLATE`): `https://<домен>/g/<код>/?erid=<erid>&ulp={url}`.
- **AliExpress WW** (`AFFILIATE_ALIEXPRESS_TEMPLATE`): `https://<домен>/g/<код>/?ulp={url}`, **без `erid`**. Программа WW отслеживает ссылки на `aliexpress.com`; для `aliexpress.ru` нужна программа AliExpress RU&CIS, её отдельно подключают в Admitad.

Остальные магазины: `AFFILIATE_OZON_TEMPLATE`, `AFFILIATE_WILDBERRIES_TEMPLATE`, `AFFILIATE_LAMODA_TEMPLATE`, `AFFILIATE_GOLDAPPLE_TEMPLATE`, `AFFILIATE_YANDEX_MARKET_TEMPLATE`, `AFFILIATE_OTHER_TEMPLATE`.

## Перед включением
1. Получить от поддержки Admitad ответ про маркировку (erid, пометка «Реклама») и допустимость редиректа через `/go/`.
2. Прочитать правила программы и убедиться, что поисковые фразы и товары не нарушают их. Для Lamoda, Золотого яблока и ЛЭТУАЛЬ запреты реализованы в `packages/db/src/partner-rules.ts`.
3. Добавить строку в `/opt/wishlist/.env`, перезапустить сервис и один раз проверить переход по ссылке из списка. Не кликать по своим ссылкам повторно: программы запрещают самоклики.

## Правила Читай-города (14.10.2026)
Контентные сайты: можно. Промокоды не из сети Admitad запрещены. Новый клиент (нет выполненного заказа за 365 дней): 8,65%, старый: 4,81%. Минус-слова для контекста: «читай-город», «читай город», «читайгород», chitai-gorod.

## Правила МТС, важные для сайта (14.10.2026)
- Контентные сайты: можно. Контекстная реклама запрещена, слова «МТС» и «MTS» нельзя использовать в ключах для рекламы.
- Нельзя использовать креативы, не согласованные с рекламодателем, и промокоды не из сети Admitad.
- Не оплачиваются: заказы юрлиц, предзаказы, заказы, выкупленные в течение 15 минут, 4 и более заказа смартфонов в месяц от одного покупателя.

## Де-Парфюм (16.10.2026)
- Сайт `de-parfum.ru`, шаблон `AFFILIATE_DEPARFUM_TEMPLATE=https://<домен-сети>/g/<код-площадки>/?erid=<erid>&ulp={url}`. Рекламодатель: ИП Банникова Инесса Владимировна, ИНН 661219938108 (блок «О рекламодателе» в карточке программы).
- Публичные цифры: EPC 747 ₽, CR 0,42%, подтверждение 73%, средний чек 4 500 ₽, холд 14–21 день. Условия: CPA 5,41% с оплаченного заказа и CPC 8,00 ₽ за клик по России. EPC держится в основном на CPC.
- Разрешённый трафик: SEO-сайты, витрины, соцсети, контекст и таргет, email по белым базам, купонные и кэшбэк-проекты. Запрещены мотивированный и adult-трафик, спам, боты, cookie-stuffing, мошенничество. Запретов на бренды и слова в общих правилах нет.
- Поиск на сайте магазина работает сторонним виджетом без обычного адреса, поэтому подбор по идее невозможен. Мы ведём на разделы каталога (карточки в `brand-offers.ts`).

## Общие правила CPC Admitad (16.10.2026)
- Платятся только уникальные клики реальных пользователей, прошедшие антифрод. Повторные клики одного пользователя, устройства или IP могут не оплачиваться. Admitad смотрит поведение на сайте рекламодателя: время и глубину.
- Запрещены: закупленный трафик и арбитраж, боты и скрипты, покупка и стимулирование кликов (деньги, бонусы, конкурсы), скрытые и принудительные клики, ссылки в элементах, не обозначенных как реклама, **клики по собственным партнёрским ссылкам** и просьбы кликать знакомым.
- Ставка динамическая. Заработок висит в статусе «Открытый» до ежемесячной проверки в 20-х числах за прошлый месяц и может измениться.

## AliExpress RU&CIS (16.10.2026)
- Программа 25179. EPC 201 ₽, CR 4,61%, подтверждение 94%, выплата в среднем через 48 дней. Только CPA, ставка по товару 0,38–6,92% (до 69,2% за «горячие» товары). Шаблон `AFFILIATE_ALIEXPRESS_TEMPLATE=https://<домен-сети>/g/<код-площадки>/?ulp={url}` включаем только с ссылкой из программы RU&CIS, не WW.
- Заказ не оплачивается, если переход на главную страницу aliexpress.ru. Мы ведём на страницу поиска. Повышенная ставка «горячих» товаров только за ссылку на сам товар. Цифровые товары (карты, коды, билеты, игры) не оплачиваются.
- Условия сотрудничества: не использовать «халява», «дешевка», «дешевизна» (а «недорогой» и «дешёвый» можно), не очернять конкурентов, продавцов и AliExpress, не сравнивать товары с копиями известных брендов («туфли Zara — распродажа на AliExpress»). Реализовано в `packages/db/src/partner-rules.ts`: при совпадении ссылка строится без партнёрского кода.
- Список запрещённых ключевых слов (бренд, опечатки, «купон», «промокод», «скидки» и т. п. на 11 языках) относится к контекстной рекламе. Контекст мы не ведём.
