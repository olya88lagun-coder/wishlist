# Иллюстрации шести новых тем

Шесть оформлений подключены к выбору, предпросмотру, странице владельца и публичному списку. Изображения сгенерированы встроенным imagegen. Каждая новая тема — отдельная покупка за 149 ₽ для одного списка, без приглашения. Доступ открывается после подтверждённой оплаты; тестовые платежи темы не активируют. Владельцам из существующего списка бесплатного доступа доступны все темы.

| Тема | Прозрачная обложка | Фон страницы |
| --- | --- | --- |
| Свадьба | wedding-decor.webp | wedding-pattern.webp |
| Тихая роскошь | quiet-luxury-decor.webp | quiet-luxury-pattern.webp |
| Космос | space-decor.webp | space-pattern.webp |
| Цветочный сад | flower-garden-decor.webp | flower-garden-pattern.webp |
| 14 февраля | valentines-decor.webp | valentines-pattern.webp |
| 8 Марта | march-8-decor.webp | march-8-pattern.webp |

Все файлы находятся в `apps/web/public/themes/`. Обложки 1536×1024 с альфа-каналом, декором по краям и свободным центром под HTML-заголовок. Фоны 1254×1254 непрозрачные, с редкими мотивами в палитре обложки. Фон повторяется на всю высоту страницы; карточки сохраняют непрозрачную белую поверхность.

Идентификаторы тем и продуктов совпадают: `wedding`, `quiet-luxury`, `space`, `flower-garden`, `valentines`, `march-8`. Каталог названий общий для студии, оферты и описаний платежа. Миграция БД не требуется: продукт и выбранная тема хранятся в существующих текстовых полях. Действующие покупки и детские приглашения сохраняются.

Оригиналы PNG и запросы генерации сохранены локально в `output/theme-assets/`; в PR включены облегчённые WebP для сайта.
