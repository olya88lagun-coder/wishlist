# Иллюстрации шести новых тем

Готовые WebP-ресурсы для будущего подключения к оформлению вишлистов. Сгенерированы встроенным imagegen. Этот PR добавляет только изображения: выбор тем, покупки, цены и действующие оформления не меняются.

| Тема | Прозрачная обложка | Фон страницы |
| --- | --- | --- |
| Свадьба | wedding-decor.webp | wedding-pattern.webp |
| Тихая роскошь | quiet-luxury-decor.webp | quiet-luxury-pattern.webp |
| Космос | space-decor.webp | space-pattern.webp |
| Цветочный сад | flower-garden-decor.webp | flower-garden-pattern.webp |
| 14 февраля | valentines-decor.webp | valentines-pattern.webp |
| 8 Марта | march-8-decor.webp | march-8-pattern.webp |

Все файлы находятся в `apps/web/public/themes/`. Обложки 1536×1024 с альфа-каналом, декором по краям и свободным центром под HTML-заголовок. Фоны 1254×1254 непрозрачные, с редкими мотивами в палитре обложки. При подключении следует проверить стыки повторения на реальной странице: бесшовность была задана генератору, но не подтверждена в браузере.

Оригиналы PNG и запросы генерации сохранены локально в `output/theme-assets/`; в PR включены облегчённые WebP для сайта.
